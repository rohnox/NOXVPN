# Special VPN 1.5.8

- Country beside the actual Xray exit IP: country.is is queried for that exact literal IP over the same bounded, cancellable local-proxy path. Returned IP and ISO country code are validated; the country name follows the app locale. IP success remains visible if geolocation fails. This is approximate IP geolocation, not the user's physical location. Public exit IP is sent to country.is for the lookup; no configuration, key or subscription link is sent. No location permission is added.
- The country name includes its flag emoji in a small dark badge with a subtle gold outline, plus a full-card country-flag background behind Connection Status, blended with a dark/light gradient scrim for legible controls. Both use only the successfully resolved country of the current connected exit. Disconnect, unknown IP, refresh/loading or failed country lookup retains the existing black/gold background. Unknown/invalid country codes never produce a guessed flag; the decorative emoji is omitted from accessibility speech while the localized country name remains readable.
- Quick Settings runtime icon now references the unique Special VPN drawable directly. Old density-specific upstream ic_stat_name PNGs previously overrode the same-name vector on real phones. No start/stop/lifecycle decision was changed. An old app's pinned tile is a separate component: remove that old tile and add Special VPN when necessary.
- Subscription cards expose Edit and Share icons. Edit routes the stable subscription ID to the existing editor. Share offers clipboard or QR using the subscription URL, resolved through MainViewModel/repository. Missing/deleted/blank entries fail explicitly. QR work runs off main and can be cancelled; links/bitmaps are never logged. No system sharing or external upload occurs.
- Version1.5.8 / base versionCode771. Package com.specialvpn.app and existing release certificate are unchanged from1.5.7. Native engines, permissions, subscriptions, quota/history and protocol behavior are retained.

Geolocation API documentation: https://country.is/ (free commercial use, IPv4/IPv6). Actual device behavior and build evidence are recorded in VALIDATION-1.5.8.md.
