# Special VPN identity

The user selected concept2: gold S ribbon in an open hexagon. selected-logo-2-reference.png is the original built-in image-generation output, copied without pixel edits. Its identical runtime copy is drawable-nodpi/ispeed_logo.png; the launcher, header and splash consume this selected design. The adaptive icon adds9dp safe-area inset. Small notifications/themed icons use a dedicated monochrome S/hexagon vector; Android small icons cannot reproduce the colored launcher image. special-vpn-logo.svg is an editable geometric companion, not a claim of pixel-identical reconstruction of the textured master.

Displayed name: Special VPN. Installation package: com.specialvpn.app. Original Java/Kotlin namespaces and licenses remain intact. This package installs independently from the previous private iSpeedTopVPN package. The upstream repository link and historical release notes keep their original names.
